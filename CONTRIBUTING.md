# Contributing

Thank you for helping improve the public OOFF NET documentation.

## What is welcome

- Corrections to public documentation.
- Clearer integration examples that stay within the published contract.
- Reproducible compatibility reports.
- Documentation of an agent adapter that you maintain or have permission to
  describe.
- Small improvements to the issue forms and troubleshooting guidance.

## What is out of scope

This repository is not the OOFF NET production source repository. Do not submit
production application code, firmware, serial implementation, Bridge internals,
private build scripts, installer artifacts, logs, credentials, or local machine
paths.

Do not publish prompts, agent responses, source code, tool arguments, file
contents, API keys, or other customer data in an issue or pull request.

## Documentation changes

1. Keep claims precise and mark compatibility as `Verified`, `Testing`,
   `Planned`, or `Not currently supported`.
2. Do not invent support for an agent or platform that has not been tested.
3. Keep examples minimal and limited to the public adapter contract.
4. Check the diff for secrets, private paths, binaries, and generated files.

Please open an issue before proposing a large change to the public contract.
